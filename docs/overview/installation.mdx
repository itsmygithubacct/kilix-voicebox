---
title: "Installation"
description: "Candidate installation boundary"
---

This repository provides a local build candidate, not a public release package.
Use the frozen uv.lock and bun.lock for development.

Speech providers and model payloads are installed separately through the
release-approved content transaction. Voicebox contains no model installer and
does not download content on first use. Until exact runtime profiles and
licence terms are accepted, the provider inventory remains empty and runtime
operations fail closed.

Public repository creation and release publication are owner-reserved.
