---
title: "Quick start"
description: "Start the local provider-first Voicebox candidate"
---

1. Start the independently installed Kilix speech providers.
2. Start the bundled Tauri application, or configure one shared backend/Vite
   development session credential before running make dev-backend.
3. Create a profile and add exactly one consentable PCM WAV sample.
4. Enter text, assert consent, and generate.
5. Retrieve committed output through the history view.

If a provider reports RUNTIME_UNSELECTED or MODEL_MISSING, use the approved
content workflow outside Voicebox. The application does not fetch models.

Voicebox uses only the local product endpoint at http://127.0.0.1:17493.
