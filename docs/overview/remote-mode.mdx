---
title: "Local-only boundary"
description: "Why remote mode is unavailable"
---

Remote mode is intentionally unsupported. Voicebox fixes its product API to
127.0.0.1 and restricts browser origins to the local Tauri development and
application origins.

Speech providers are also local. They use fixed AF_UNIX SOCK_SEQPACKET endpoints
inside a private XDG runtime directory and require kernel-verified same-UID
peers.

Do not expose the product API through a wildcard bind, reverse proxy, tunnel, or
LAN address. Remote inference requires a separately designed and reviewed trust
contract; this candidate does not provide one.
