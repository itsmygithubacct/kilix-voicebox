title: "Troubleshooting"
description: "Stable local failure modes"
---

## RUNTIME_UNSELECTED

The provider is reachable but no accepted runtime profile is installed. This is
expected for the gate-independent candidate.

## PROVIDER_UNAVAILABLE

Check XDG_RUNTIME_DIR, private 0700 directory ownership, the fixed provider
socket, 0600 socket permissions, and provider supervision.

## CONSENT_REQUIRED

Return to the generation form and explicitly assert that the source sample is
authorized for this project.

## INPUT_SIZE or UNSAFE_INPUT

Use one non-empty mono signed-16-bit 24 kHz PCM WAV source no longer than 30
seconds. Transcription uploads must remain within the provider byte bound.

## Local API unavailable

The product API is fixed to 127.0.0.1:17493. There is no remote fallback.
