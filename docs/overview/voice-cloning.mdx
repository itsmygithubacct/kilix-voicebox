---
title: "Consent-bound voice cloning"
description: "Clone requests through kilix-qwen-tts"
---

A profile holds one private source sample and its reference text. Generation is
refused until the user explicitly asserts consent for the request.

Voicebox canonicalizes the sample, records its source and container digests,
capture time, and allowed use, then sends the provider a bounded anonymous
descriptor. Successful output is accepted only when the provider returns the
same source and consent bindings plus its actual model identifier and revision.

The product stores private output provenance and a reverse derived-output link.
Deleting a generation first previews the owned files and then moves audio,
provenance, and the consent link to recoverable private trash.
