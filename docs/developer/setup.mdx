---
title: "Development setup"
description: "Frozen local Voicebox development environment"
---

Use the repository locks. Do not install model runtimes into Voicebox.

Requirements:

- Python 3.12 or 3.13
- uv
- Bun 1.3.8
- the release-selected Rust toolchain and native Tauri build dependencies

From the repository root:

~~~bash
make setup-python
bun install --frozen-lockfile
make check-backend
bun x tsc --noEmit --project app/tsconfig.json
bun x tsc --noEmit --project tauri/tsconfig.json
~~~

Generate one development session credential, expose it to both processes, then
run the local product backend:

~~~bash
export KILIX_VOICEBOX_SESSION_TOKEN="$(python3 -c 'import secrets; print(secrets.token_hex(32))')"
export VITE_VOICEBOX_SESSION_TOKEN="$KILIX_VOICEBOX_SESSION_TOKEN"
make dev-backend
~~~

It binds only to 127.0.0.1:17493. Provider sockets must already be supervised
independently in the private XDG runtime directory.
