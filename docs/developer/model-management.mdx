---
title: "Provider inventory"
description: "Content-owned installation and provider-owned residency"
---

Voicebox never downloads, deletes, or scans model payloads. The model screen is
a read-only projection of the inventories reported by kilix-qwen-tts and
kilix-transcribe.

Installation, licence display, notices, integrity, quota, and removal belong to
the F100 content transaction. The compatibility load, download, and delete API
routes fail with CONTENT_OWNED. Unload only asks both providers to release
residency and reports a bounded acknowledgement count.

No runtime or model line is selected by this F104 candidate.
