## Storage boundary

Voicebox stores its relational history in the private XDG data directory. A
generation's audio and canonical provenance sidecar live together under the
private provenance store. Database paths are accepted only when they match the
generation's exact owned slot; a tampered path fails closed and is never sent to
the frontend.

Each successful generation binds these records:

- provider name, model identifier, and model revision;
- provider job and generation identifiers;
- source, consent, and output SHA-256 digests;
- output byte length and capture time; and
- a consent-derived-output link.

Raw local paths remain an implementation detail. API response serializers expose
only loopback resource paths such as `/audio/{generation_id}`.

## Export

`GET /history/{generation_id}/export` produces a ZIP containing exactly:

```text
manifest.json
audio/{generation_id}.wav
provenance.json
```

The export refuses if the audio length or digest disagrees with its canonical
provenance. `GET /history/{generation_id}/export-audio` is an explicit audio-only
selection. Imported generation archives are not accepted because they cannot be
treated as provider-produced artifacts without an admissible consent and
provenance chain.

## Recoverable deletion

The frontend first calls `GET /history/{generation_id}/delete-preview` and shows
the complete owned population—audio, provenance, consent-derived link, and
catalog recovery record—with an exact count. `DELETE /history/{generation_id}`
then archives that same population in a private trash batch and writes a
canonical recovery receipt before removing the live database index. It does not
unlink generated media. A generation used by a story refuses deletion.

Profiles, source samples, avatars, and stories use the same
preview-and-private-trash pattern. A profile referenced by any generation
refuses deletion until those generations have been handled explicitly.

## History API

| Method | Endpoint | Purpose |
| --- | --- | --- |
| `GET` | `/history` | Bounded filtered history list |
| `GET` | `/history/stats` | Aggregate history statistics |
| `GET` | `/history/{generation_id}` | One serialized history record |
| `GET` | `/history/{generation_id}/delete-preview` | Exact deletion population |
| `DELETE` | `/history/{generation_id}` | Move to recoverable trash |
| `GET` | `/history/{generation_id}/export` | Audio plus provenance export |
| `GET` | `/history/{generation_id}/export-audio` | Explicit audio-only export |
