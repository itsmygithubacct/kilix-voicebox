---
title: "Architecture"
description: "Local product orchestration and independent speech providers"
---

The desktop has three trust domains:

1. The Tauri and React UI talks to a loopback-only FastAPI product service.
2. Voicebox owns profiles, consent, provenance, history, stories, and exports in
   private XDG storage.
3. Independent kilix-qwen-tts and kilix-transcribe services own every speech
   runtime and accept bounded same-UID Unix-socket requests.

Voicebox sends no caller-selected paths, URLs, commands, environments, modules,
or imports across the provider boundary. Audio moves through at most one
SCM_RIGHTS descriptor per message. Control JSON is length-, depth-, node-, key-,
number-, and event-bounded.

Generated API values use opaque identifiers and loopback resource URLs. Local
paths stay in the product database and never serialize to the frontend.
