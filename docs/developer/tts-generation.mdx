---
title: "Speech generation"
description: "Provider-first consent-bound synthesis"
---

Voicebox contains no synthesis runtime. The product backend validates the
request, resolves exactly one product-owned source sample, canonicalizes it to
bounded 24 kHz mono PCM, records explicit consent, and passes one anonymous file
descriptor to the fixed kilix-qwen-tts socket.

The provider owns model selection, loading, inference, cancellation, and
residency. Voicebox verifies the response identity, output length and digest,
canonical WAV shape, prompt digest, consent digest, model identifier, and model
revision before committing output.

Generated audio and provenance are private 0600 files. A reverse consent link
records the derived generation, model revision, and output digest. API clients
receive /audio/{generation_id}, never a local path.

Until F100 installation and F106 profile gates select a runtime, providers must
return RUNTIME_UNSELECTED. This repository does not silently fetch a fallback.
