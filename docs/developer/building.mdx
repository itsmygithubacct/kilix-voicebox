---
title: "Building"
description: "Locked provider-free Voicebox builds"
---

The Python sidecar build is resolved from uv.lock and contains product
orchestration only:

~~~bash
make setup-python
./scripts/build-server.sh
~~~

The build emits the sidecar plus a provenance JSON document containing the
source commit and tree, lock digest, binary digest, byte length, fixed provider
endpoints, and an explicit no-embedded-runtime declaration.

Frontend controls use bun.lock:

~~~bash
bun install --frozen-lockfile
bun run --cwd app build
bun run --cwd tauri build
~~~

Tauri packaging additionally requires the release-selected Rust toolchain and
host GUI development packages. A build never downloads model content.
