---
title: "Transcription"
description: "Private kilix-transcribe provider flow"
---

Voicebox contains no ASR engine. It stages one bounded upload in a private
product cache, passes one read-only file descriptor to the fixed
kilix-transcribe socket, verifies same-UID peer credentials and the bounded
response, and removes the staged file in a finally path.

The provider owns engine selection, decoding, VAD, language identification,
timestamps, translation, diarization, cancellation, and residency. The
candidate transport supports text, JSON, WebVTT, and SRT result modes without
selecting an engine route.

No transcript copy is retained by Voicebox unless a separate product operation
explicitly stores it.
