---
title: "Local trust boundary"
description: "Loopback and same-UID authorization"
---

The product API is reachable only on loopback and is intended for the bundled
Tauri application. CORS permits only the fixed local application and
development origins. Every application request also carries a freshly generated
`X-Kilix-Voicebox-Session` credential. Media elements use the same credential
in an ephemeral URL; access logging is disabled so it is not recorded. The
credential is retained only in process memory and changes with the sidecar.

Provider authorization is a separate boundary and does not use the product
credential. Fixed private Unix sockets,
0700 runtime-directory ownership, 0600 socket ownership, and Linux SO_PEERCRED
same-UID checks establish the local peer boundary.

This is defense for a loopback fallback, not a remote authentication scheme. Do
not publish or proxy the API.
