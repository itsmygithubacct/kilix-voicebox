---
title: "Local API"
description: "Loopback Voicebox product API"
---

The API is available only at http://127.0.0.1:17493. It is a product-data API,
not a model-runtime API. Requests require the per-process
`X-Kilix-Voicebox-Session` credential.

Generation requires profile_id, text, language, and consent_asserted=true.
Successful JSON responses identify audio as /audio/{generation_id}. Sample
responses identify audio as /samples/{sample_id}. Profile avatars use
/profiles/{profile_id}/avatar. No response contains a local filesystem path.

Provider and internal failures are mapped to bounded code objects. Raw
exceptions are never returned. Model installation and removal routes return
CONTENT_OWNED.
